🏨 API_Hotel

API desenvolvida em Python como exercício prático, com o objetivo de implementar uma API REST para a gestão de hotéis.

O projeto permite trabalhar com operações de gestão de hotéis e utilizadores, explorando conceitos de desenvolvimento de APIs, organização de código e interação com uma base de dados.

🚀 Funcionalidades
Gestão de hotéis.
Inserção de novos hotéis.
Consulta e listagem de hotéis.
Eliminação de hotéis.
Gestão de utilizadores.
Autenticação de utilizadores (Login).
Armazenamento de dados numa base de dados SQLite.

---

🛠️ Tecnologias utilizadas
Python – Linguagem de programação.
SQLite – Base de dados.
REST API – Arquitetura de comunicação.
Bruno – Testes e organização de pedidos à API.

---

🧪 Testes da API

Os pedidos à API podem ser testados através do Bruno, utilizando as coleções disponíveis na pasta collections/Hoteis.

Entre os pedidos incluídos encontram-se operações de criação, consulta, listagem, eliminação de hotéis e autenticação de utilizadores.

🎯 Objetivo do projeto

Este projeto foi desenvolvido no âmbito de um exercício prático de programação em Python, com o objetivo de consolidar conhecimentos sobre:

Desenvolvimento de APIs REST.
Programação em Python.
Organização e estruturação de projetos.
Bases de dados SQLite.
Operações CRUD (Create, Read, Update e Delete).
Autenticação de utilizadores.
Testes e validação de endpoints.
